# Text Cleaner & Word Counter 📝

This Python script computes the **total word count** of a text string, while **removing non-alphabetic characters** 🚫.   

## 📅 Version History

* **v1.0** - Initial Release: Counts the number of words.
* **v1.1** - 1.1 Release: Faster execution and more memory-efficient. The user needs/ can input his own text.
