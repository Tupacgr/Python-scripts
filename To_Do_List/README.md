# To-Do List Manager 📝

A Python CLI utility designed to organize, prioritize, and save daily tasks efficiently.

## 📝 Description

This script utilizes Python **List Manipulation** and **File Handling** to manage tasks. It offers a dynamic menu system where users can add standard or urgent tasks, view them in chronological or alphabetical order, and save the final list to a local text file. It ensures a clean interface by clearing the terminal between actions.

## 🛠️ Technologies Used

* Python 3.x
* Standard Libraries: `os`, `time`
* Concepts: List Methods (`append`, `insert`, `sort`), File I/O (`open`, `write`), Exception Handling, While Loops, Input Sanitization

## 📅 Version History

* **v1.0** - Initial Release: Basic task addition and viewing.
* **v1.1** - Tasks Saving: Added a "Save my tasks" feature that stores the active user's tasks in tasks.txt file.
