# Cartesian Product Calculator 🧮

This Python script computes the **Cartesian product** of a user-defined set of numbers. 
It prompts the user to input the elements the set contains, while automatically **removing duplicates** 🚫. 
Users also specify the desired combination size, and the script generates and prints the ordered results using the `itertools` library 🐍.
