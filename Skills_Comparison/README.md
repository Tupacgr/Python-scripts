# Skills Comparison 🎯

A Python CLI tool designed to compare skill sets between two job candidates.

## 📝 Description

This script utilizes Python **Sets** to perform logical operations on candidate skills. It helps identify common grounds, unique specializations, and skill gaps between two potential hires.

## 🚀 Features

* **Add Skills:** Dynamically add technical skills for Candidate A and Candidate B.
* **Intersection:** Find common skills (where candidates overlap).
* **Union:** View the total combined skill set of both candidates.
* **Difference:** Identify skills that one candidate has but the other lacks.
* **Symmetric Difference:** See unique skills possessed by each candidate (non-overlapping).
* **Management:** Remove specific skills from any candidate.

## 🛠️ Technologies Used

* Python 3.14.0
* Standard Libraries: `os`, `time`
* Concepts: Sets, Loops, Input Handling, CLI Menu
