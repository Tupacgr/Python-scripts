# Rock Paper Scissors 🎮

A Python CLI game designed to play the classic hand game against the computer.

## 📝 Description

This script utilizes Python **Control Flow** and **Randomization** to simulate matches. It handles user inputs, validates choices, and determines the winner based on standard game rules, providing a clean and interactive terminal experience.

## 🛠️ Technologies Used

* Python 3.14
* Standard Libraries: `os`, `random`, `time`
* Concepts: Functions, While Loops, Conditional Logic (`if/elif`), Input Validation
